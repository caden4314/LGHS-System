# LGHS 0.5.1 to 0.6 bridge

Existing 0.5.1 student Pis require one compatibility refresh before they can honor immutable exact-SHA deployment targets from the 0.6 controller.

The `release-0.5.1-bluetooth-bootstrap` branch carries the current typed executor, netqueue, and updater transport scripts while retaining the 0.5.1 installer/version. After a student refreshes this branch once, a subsequent fleet `lghs-update` command with `payload.target_commit` can jump directly to the requested immutable 0.6 commit.

This bridge is intentionally narrow: it does not install 0.6 features by itself and does not change the student version from 0.5.1. It only upgrades the command/update transport needed for the exact-commit migration.
